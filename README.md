# Excel Sheet Application using Java
This project uses java to create, write, read, and copy excel sheets. The menu in the console shows all the functions you can perform on excel sheets
where you can select one option (1 to 5), it ends when you choose 5.

# What I used
1. eclipse IDE for Java Developers - 2022-06
2. openjdk 17.0.11 2024-04-16
3. Windows

# Inputs 
It takes directory path (Example: F:\Excel files for project) , file name (Exmaple: trailtwo.xlsx), row index (Example: 0), colomn index (Example: 3) 
as inputs according to the case.
Copy Excel sheet:
Both the source and destination excel files should already be created to use this function.

# Adding jar files
Follow the steps below:
1. Download the "jar files for excel app" folder
2. right click on the "ExcelApplicationInternship" project
3. go to Build path
4. go to configure build path
5. Libraries
6. click on "class path"  (options get highlighted on the right side)
7. choose Add External JARs..
8. choose all the files from "jar files for excel app"
9. Apply and close
